# Reinvasion
This repository features all analyses related to chapter 2 (reinvasion and resistance). Each Rmd file explores a different piece of the paper.

# Data

## Experimental Restoration
A large, complex restoration experimented was conducted from 2022-2026 to examine how to remove iceplant and restore coastal sage scrub, dune, and wetland ecosystems.
Here, only experimental restoration in coastal sage scrub habitats is analyzed. 

## Reinvasion Experiment
Iceplant cuttings were outplanted to examine reinvasion dynamics and mechanisms of resistance. 
Survival analysis was used to determine how native shrub species best resist invasion.
